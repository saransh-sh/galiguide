# Triage Labels — GaliGuide

Mapping of canonical agent triage roles to repository labels:

| Label in Skills | Label in Our Tracker | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter or municipal coordinator for more info |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for automated agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human verification (e.g. physical vendor audit in Indore) |
| `wontfix` | `wontfix` | Out of scope or invalid request |
| `domain:spatial` | `domain:spatial` | Involves Haversine math, coordinates, or Leaflet mapping |
| `domain:privacy` | `domain:privacy` | Involves phone consent, data redaction, or DPDP compliance |
| `domain:bilingual` | `domain:bilingual` | Involves Hindi/Devanagari localization or indexing |
